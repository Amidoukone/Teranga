# Cycle unifié des demandes

Le cycle commun Teranga s’applique aux services, besoins, projets et biens. Le type de demande change les champs et l’équipe responsable, jamais les garanties de suivi.

`créée → qualifiée → affectée → en cours → preuve déposée → validation client → clôturée`

## Responsabilités

| Étape | Responsable | Sortie obligatoire |
|---|---|---|
| Créée | client | besoin compréhensible et périmètre |
| Qualifiée | agent | catégorie, urgence, zone et estimation |
| Affectée | agent/master | exécutant confirmé et délai |
| En cours | prestataire/agent | journal d’exécution |
| Preuve | exécutant | photo, document, reçu ou compte rendu |
| Validation | client/agent | acceptation ou litige |
| Clôturée | système/admin | statut, rapprochement et KPI |

Toute exception (annulation, absence, litige, retard) est journalisée et escaladée sans supprimer l’historique.
